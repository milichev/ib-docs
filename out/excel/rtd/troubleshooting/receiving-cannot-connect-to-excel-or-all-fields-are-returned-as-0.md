# Receiving "Cannot connect to Excel" or all fields are returned as "0"

Excel may begin to display a value of "0" or a "Cannot connect to TWS" error message. Before contacting support, please adhere to these steps:

1. Validate the [TWS Settings are configured properly](/docs/excel/rtd/download-tws-or-ib-gateway/tws-configuration-for-excel)
2. [Uninstall the Trader Workstation and the TWS API](../downloads/uninstall-the-api.md)
3. Upgrade to the [Latest Trader Workstation](https://interactivebrokers.com/en/trading/download-tws.php?p=offline-latest).
4. Download and install [the Latest TWS API](https://download2.interactivebrokers.com/installers/tws-api/index.html)

In some instances, users will also need to [manage their DLLs](dll-management.md).
