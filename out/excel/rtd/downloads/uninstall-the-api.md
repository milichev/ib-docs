# Uninstall The API

In some instances, users may find they need to uninstall the TWS API. This can be resolved in a few brief steps.

1. Click the Windows button
2. Begin typing "Control Panel". This will automatically search for the program.
3. Click "Control Panel" from the list of options in the Windows menu.

![](/docs/_fern-img/baa80c206e61c45d585db40ae5bfd38190e4f5fea060ff3975697a1ce54bb80f.webp)

**Category View**\
4(a). From the Control Panel window, select "Uninstall A Program".

![](/docs/_fern-img/e0bcceacd0f620bb235b93060c502c13a5d506f512b204a41ac0a7544cb7937e.webp)

**Icon View**\
4(b). From the Control Panel window, select "Programs and Features".

![](/docs/_fern-img/e60295934be06ecbddb27e7e3110d90d61cb988c094b3676518f41924b02d620.webp)

5. Select "TWS API" from the list of programs.
6. Click "Uninstall" above the list of programs.
