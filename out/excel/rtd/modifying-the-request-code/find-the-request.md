# Find The Request

Within the solution file, you will need to navigate to the TwsRtdServerMktDataRequest.cs file. This file contains the request for [EClient.reqMktData](../../../tws-api/doc/md/streaming-data.md#request-watchlist-data), which effects the underlying behavior. The request is on line 73.
