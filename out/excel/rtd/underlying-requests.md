# Underlying Requests

As stated within the [Architecture](introduction.md) section, the Excel RTD API is built on the underlying Java API with standard Visual Basic Translations to allocate the data onto the Excel sheets. For additional insight into the underlying methods, see the [TWS API Documentation](../../tws-api/doc/introduction.md).
