# Review Trust Center Settings

1. DdeSocketBridge app must be running and connected
2. Open "Excel > File > Options > Excel Options > Trust Center > Trust Center Settings"
3. Make sure that :
   1. ActiveX Settings: "ActiveX Settings for all Office Applications -> Disable all controls without notification" is NOT selected (any other button should be selected)
   2. Macro Settings: "Macro Settings -> Enable VBA macros" is selected
   3. External Content: "Security settings for Dynamic Data Exchange – Enable Dynamic Data Exchange Server Lookup" is checked
4. After settings were changed, Excel must be restarted
