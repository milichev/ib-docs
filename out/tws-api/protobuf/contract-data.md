## ContractData

| Field | Type | Description |
| ----- | ---- | ----------- |
| `reqId` | `int32` | Unique request identifier used for tracking across EWrapper |
| `contract` | `Contract` | Contract object containing defining characteristics for ticker. |
| `contractDetails` | `ContractDetails` | Object containing a Contract object along with related attributes for trading. See ContractDetails for more details. |
