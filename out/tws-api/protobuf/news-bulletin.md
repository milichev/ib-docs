## NewsBulletin

| Field | Type | Description |
| ----- | ---- | ----------- |
| `newsMsgId` | `int32` | Unique identifier to track a given news article. |
| `newsMsgType` | `int32` | Bulletin type to define a given article. |
| `newsMessage` | `string` | Content of a given news article. |
| `originatingExch` | `string` | Exchange reporting a bulletin. |
