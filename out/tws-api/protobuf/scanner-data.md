## ScannerData

| Field | Type | Description |
| ----- | ---- | ----------- |
| `reqId` | `int32` | Unique request identifier used for tracking across EWrapper |
| `scannerDataElement` | `ScannerDataElement` | Represents a single scanner data object, which contains rank, contract, marketName, distance, benchmark, projection, and comboKey. |
