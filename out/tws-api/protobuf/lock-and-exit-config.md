## LockAndExitConfig

| Field | Type | Description |
| ----- | ---- | ----------- |
| `autoLogoffTime` | `string` | Define the 12-hour time to logoff or restart. Formatted as "HH:MM" |
| `autoLogoffPeriod` | `string` | Declare "AM" or "PM" for your logout time. |
| `autoLogoffType` | `string` | Declare if the system should "logoff" or "restart" at the defined time. |
