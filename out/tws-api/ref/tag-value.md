# Introduction

Convenience class to define key-value pairs.

| Field   | Type     | Description                           |
| ------- | -------- | ------------------------------------- |
| `Tag`   | `string` | The Key of a Key:Value pair.          |
| `Value` | `string` | The data representation for your key. |
