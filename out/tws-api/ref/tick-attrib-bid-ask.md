## TickAttribBidAsk

| Field | Type | Description |
| ----- | ---- | ----------- |
| `bidPastLow` | `bool` | Indicates the bid price is below the current Low for the day. |
| `askPastHigh` | `bool` | Indicates the ask price is above the current High for the day. |
