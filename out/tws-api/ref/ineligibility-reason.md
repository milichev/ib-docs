## IneligibilityReason

| Field | Type | Description |
| ----- | ---- | ----------- |
| `id` | `string` | The order's unique identifier. If a new order is placed with an order ID less than or equal to the order ID of a previous order an error will occur |
| `description` | `string` | Description of the contract. |
