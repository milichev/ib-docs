# Index

**Symbol:** String. Specify the symbol for the index.

**SecType:** String. Specify IND.

**Exchange:** String. Specify the host exchange for the index.

**Currency:** String. Specify the base currency of the index.

```
symbol = "DAX"
secType = "IND"
exchange = "EUREX"
currency = "EUR"
```
