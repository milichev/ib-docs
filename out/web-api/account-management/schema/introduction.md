# Introduction

While fields for registration will vary based on various factors including the account type, IB entity, and permissions, the JSON should always include the following:

* customer
* accounts
* users

This section includes information on objects and attributes for client registration, validations, and supported enumerations. List of required fields for client application based on account type can be found [here](../client-registration/data-for-client-registration.md).

### Enumerations

The `/api/v1/enumerations/{enumerationType}` can be used to obtain supported enumerations for select attributes and objects.
