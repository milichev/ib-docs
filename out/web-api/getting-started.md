# Getting Started

### Retail

For retail and individual clients, Authentication to our WebAPI is managed using the Client Portal Gateway, a small java program used to route local web requests with appropriate authentication. Click [here](authentication/cpgw/installation-authentication.md) to get started.

### Institutional or Third Party

We understand that enterprise integrations can be more complex. We have a designated API Solutions team that will help in creating solution that aligns with your business objectives. To get started, please contact our API Solutions (e-mail: **[api-solutions@interactivebrokers.com](mailto:api-solutions@interactivebrokers.com)**) with the following information:

* Firm Name
* Firm Type (ie. Introducing Broker, Financial Advisor OR Third Party Service Provider)
* API Services which you are interested in using (ie. Registration, Funding, Single Sign On, View Portfolio Data, Trading, Reporting)
* Describe intended usage (1-2 sentences)
