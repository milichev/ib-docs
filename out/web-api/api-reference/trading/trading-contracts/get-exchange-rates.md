# Currency Exchange Rate

GET https://localhost:5000/v1/api/iserver/exchangerate

Obtains the exchange rates of the currency pair.

Reference: https://ibkrcampus.com/docs/web-api/api-reference/trading/trading-contracts/get-exchange-rates

## Authentication

- `Authorization` header (bearer token, required) — SSO bearer token.

## Servers

- `https://localhost:5000` (Client Portal Gateway, default)
- `https://api.ibkr.com` (Production)
- `https://qa.interactivebrokers.com` (Sandbox)

## Request

### Query parameters

- `target` (string, required)
- `source` (string, required)

## Response

### 200

Successful requests return the currency exchange rate of the target currency value divided by the source currency.

- `rate` (double, optional) — Returns the exchange rate for the currency pair.

## Errors

### 400 Bad Request Error

Missing, empty, non-numeric, or out-of-range parameter. The `error` field is always prefixed with `Bad Request:`.

- `status` (long, optional)
- `error` (string, optional)
- `message` (string, optional)

### 401 Unauthorized Error

Missing, invalid, or unparseable Authorization token.

- `status` (long, optional)
- `error` (string, optional)
- `message` (string, optional)

### 500 Internal Server Error

internal server error, returned when incoming request cannot be processed. It can sometimes include subset of bad requests. For example, wrong accountId passed and it can only be detected later in handling request. Error contains reason of the problem.

- `error` (string, optional) — error reason

### 503 Service Unavailable Error

service is unavailable. For example if request takes more than 10s due to some internal service unavailability, request aborted and this status returned

- `error` (string, optional) — error reason
- `statusCode` (long, optional) — mimic response status code

import Foundation

let headers = ["Authorization": "Bearer <token>"]

let request = NSMutableURLRequest(url: NSURL(string: "https://localhost:5000/v1/api/iserver/exchangerate?source=USD&target=EUR")! as URL,

let dataTask = session.dataTask(with: request as URLRequest, completionHandler: { (data, response, error) -> Void in

  } else {

    print(httpResponse)
  }
})
