# IBKR WebAPI | Trading Web API

* Pacing limitations for the /iserver/marketdata/history endpoint have been modified. Requests are now capped at 10 requests per second or 50 requests per minute.
* The /hmds/scanner endpoint is now considered deprecated and has been removed from the documentation.
* The secType parameter has been removed from the /iserver/secdef/search endpoint as the value has been deprecated.
