# Receiving Data

To request a specific Tick type, you can utilize the 'qt' parameter in the complex syntax by specifying it (for example, "qt=Bid") or simply enter its name at the end of a simple syntax formula (for example, "AAPL\@SMART BidSize"). Explore the various available tick types in our [Generic Tick Types section.](../topic/generic-tick-types.md)\
\*It is important to note that each cell can only return one tick type (one quote).
