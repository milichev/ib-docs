# Introduction

Requests made using our Excel DDE will respond in [single variable structures](single-value-responses.md) such that a single value will be returned to a given cell. In other scenarios, requests will handle responses through an array passed to Visual Basic. These [array value responses](array-value-responses.md) must be handled through Visual Basic to assign a range of cells in your sheet to assign the data.
