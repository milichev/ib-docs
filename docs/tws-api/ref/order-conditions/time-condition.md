# Time Condition

Time condition used in conditional orders to submit or cancel orders at specified time.

| Field   | Type     | Description                                                                  |
| ------- | -------- | ---------------------------------------------------------------------------- |
| `Value` | `string` |                                                                              |
| `Time`  | `string` | Time field used in conditional order logic. Valid format: YYYYMMDD HH:MM:SS. |
