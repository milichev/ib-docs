## Configure Trader Workstation Settings

1. Launch TWS

2. Log in

3. Open settings (gear icon in top right)

4. Configure the following:

* Enable "ActiveX and Socket Clients"
* Disable "Read-Only API"
* Verify the "Socket Port" value
