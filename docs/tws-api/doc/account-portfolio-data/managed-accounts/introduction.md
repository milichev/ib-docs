# Introduction

A single user name can handle more than one account. As mentioned in the [Connectivity](../../connectivity/introduction.md) section, the TWS will automatically send a list of managed accounts once the connection is established. The list can also be fetched via the IBApi.EClient.reqManagedAccts method.
