# Cancel Positions Request

#### EClient.cancelPositions()

Cancels a previous position subscription request made with EClient.reqPositions().

#### Python

```python
self.cancelPositions()
```

#### Java

```java
client.cancelPositions();
```

#### C++

```cpp
m_pClient->cancelPositions();
```

#### C#

```csharp
client.cancelPositions()
```

#### VB.NET

```vbnet
client.cancelPositions()
```
