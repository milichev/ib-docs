# Request Family Codes

#### EClient.reqFamilyCodes()

Requests family codes for an account, for instance if it is a FA, IBroker, or associated account.

#### Python

```python
self.reqFamilyCodes()
```

#### Java

```java
client.reqFamilyCodes();
```

```cpp
m_pClient->reqFamilyCodes();
```

#### C#

