# IBKR TWS API

* The [TWS API Limitations](/docs/tws-api/doc/notes-limitations/limitations) page(s) have been updated to consolidate information and improve clarity in how the TWS and TWS API are related.
* The link to Trade Conditions has been removed from the [Receive Tick By Tick Data](../../../doc/md/live-ticks.md#receive-tick-data) page while the content is under internal review.
* [Error Codes](../../../doc/error-handling/error-codes.md) has been updated to include error code 0 and error code 10213 and their affiliated descriptions.
* [Event Contract Example](/docs/tws-api/doc/event-trading/contract-definition-discovery/forecast-ex-contract-example) has been updated to include references for `FORECASTX`, `KALSHI`, and `CME`.
* [Overnight Orders](../../../doc/orders/place-order/trading-the-overnight-session.md) has been updated to better reflect trading the `OVERNIGHT` and `OVERNIGHT+DAY` trading sessions.
* Combo orders in [Trigger Methods](../../../doc/orders/trigger-methods.md) have been updated to use `Bid/ask` trigger type instead of `Last` as the default.
