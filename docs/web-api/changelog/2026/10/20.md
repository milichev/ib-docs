* A new dedicated [*Websocket Reference*](../../../ws/introduction.md) has been added to the documentation.

See ["smd"](../../../ws/streaming-data.md#subscribe-to-streaming-market-data) and ["umd"](../../../ws/streaming-data.md#unsubscribe-from-streaming-market-data) message details in the new [Streaming Data](../../../ws/streaming-data.md) page.
