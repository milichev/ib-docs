# Regular Server Maintenance

Interactive Brokers maintains regularly scheduled maintenance for all users of the Web API. The system reset time is unique from that of the standard Trader Workstation connection. Clients will see disconnects at midnight of their connecting region.

| Server Reset Times             | North America    | Europe     | Asia      |
| ------------------------------ | ---------------- | ---------- | --------- |
| **Local Time**                 | 00:00 US/Eastern | 00:00 CEST | 00:00 HKT |
| **Universal Time Coordinated** | 20:00 UTC        | 02:00 UTC  | 08:00 UTC |
