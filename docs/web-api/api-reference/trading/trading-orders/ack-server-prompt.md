# Dismiss Server Prompt

POST https://localhost:5000/v1/api/iserver/notification
Content-Type: application/json

Respond to a server prompt received via ntf websocket message.

Reference: https://ibkrcampus.com/docs/web-api/api-reference/trading/trading-orders/ack-server-prompt

## Authentication

- `Authorization` header (bearer token, required) — SSO bearer token.

## Servers

- `https://localhost:5000` (Client Portal Gateway, default)
- `https://api.ibkr.com` (Production)
- `https://qa.interactivebrokers.com` (Sandbox)

## Request

### Body (application/json)

This endpoint expects an object.

- `orderId` (long, optional) — IB-assigned order identifier obtained from the ntf websocket message that delivered the server prompt.
- `reqId` (string, optional) — IB-assigned request identifier obtained from the ntf websocket message that delivered the server prompt.
- `text` (string, optional) — The selected value from the "options" array delivered in the server prompt ntf websocket message.

## Response

### 200

Status of submitted prompt

- `string`

```swift
import Foundation

let headers = [
  "Authorization": "Bearer <token>",
  "Content-Type": "application/json"
]
let parameters = [] as [String : Any]

let postData = JSONSerialization.data(withJSONObject: parameters, options: [])

let request = NSMutableURLRequest(url: NSURL(string: "https://localhost:5000/v1/api/iserver/notification")! as URL,
                                        cachePolicy: .useProtocolCachePolicy,
                                    timeoutInterval: 10.0)

request.allHTTPHeaderFields = headers
request.httpBody = postData as Data

let session = URLSession.shared
let dataTask = session.dataTask(with: request as URLRequest, completionHandler: { (data, response, error) -> Void in
  if (error != nil) {
    print(error as Any)
  } else {
    let httpResponse = response as? HTTPURLResponse
    print(httpResponse)
  }
})

dataTask.resume()
```
